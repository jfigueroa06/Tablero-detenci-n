El tablero está funcionando, pero solo para ti: lo que marques no le llega a nadie. Para que todo el equipo trabaje sobre el mismo tablero, sigue estos cuatro pasos. Toma unos quince minutos y no hay que programar nada.

1
Crea una cuenta gratis en Supabase Entra a supabase.com, regístrate y crea un proyecto nuevo. Cualquier nombre sirve. Elige la región South America (São Paulo), que es la más cercana.
2
Crea las cinco tablas Dentro de tu proyecto, en el menú lateral, abre SQL Editor y pega este texto completo. Después aprieta Run. Debería decir «Success». 
create table plan (
  id int primary key default 1,
  name text, win_start text, win_end text,
  structure jsonb, plan_id text, updated_at timestamptz default now()
);
create table marks (
  key text primary key,
  status text not null,
  pct smallint,
  plan_id text,
  who text, at timestamptz default now()
);
create table log (
  id bigserial primary key,
  plan_id text,
  who text, txt text, at timestamptz default now()
);
create table owners (
  pk text not null,
  plan_id text not null,
  name text,
  who text, at timestamptz default now(),
  primary key (plan_id, pk)
);

alter table plan   enable row level security;
alter table marks  enable row level security;
alter table log    enable row level security;
alter table owners enable row level security;

create policy abierto_plan   on plan   for all using (true) with check (true);
create policy abierto_marks  on marks  for all using (true) with check (true);
create policy abierto_log    on log    for all using (true) with check (true);
create policy abierto_owners on owners for all using (true) with check (true);

Copia tus dos claves a este archivo En Supabase ve a Project Settings › API. Copia el Project URL y la clave anon public. Después abre este archivo .html con el Bloc de notas y pégalas en las dos líneas de arriba, entre las comillas. Guarda.

Reparte el archivo Manda el archivo guardado a tu equipo, o súbelo a una carpeta compartida. Todos los que lo abran ven y editan el mismo tablero.
Cualquier persona con este archivo puede ver y modificar el tablero. No hay contraseñas. Es lo que pediste, y para una detención con gente entrando y saliendo de turno tiene sentido — pero no repartas el archivo fuera del equipo.

Cargar la carta Gantt

Este tablero lee el archivo XML que exporta Microsoft Project. En Project: Archivo › Guardar como, y en «Tipo» elige Datos XML (*.xml). El .mpp no sirve: es un formato cerrado que ningún navegador puede abrir.

Curva S · programado vs. real

Compara cuánto se debería llevar avanzado según la carta Gantt original, contra lo que el equipo ha ido marcando de verdad en el tablero.

Programado Real Hoy
Ambas curvas ponderan por duración: una subtarea de 48 horas pesa mucho más que una de 15 minutos — la misma lógica que usa MS Project. El avance real cuenta el avance que ya traía el archivo desde el momento en que se cargó, y lo reemplaza por lo que el equipo marque en el tablero apenas alguien lo haga — la marca del equipo siempre tiene la última palabra sobre lo importado. El avance programado supone que cada subtarea aporta su peso completo al llegar su fecha de término planificada.
